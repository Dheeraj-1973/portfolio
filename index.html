Research and projects

FreshGuard

Human-in-the-loop decision support for environmental risk assessment in perishable-food shelf-life monitoring

Team lead and prototype developer First-author paper accepted at ICACTCE '26 (Paper ID 128)

Perishable food can spoil when temperature and humidity drift, and automated alerts are only useful if someone is accountable for acting on them. FreshGuard flags risky batches and keeps a person in charge of every alert.

  1. Simulated readings Temperature and humidity for each batch
  2. Rule-based assessment Environmental stress per batch
  3. Batch status Healthy Warning Critical
  4. One open alert An existing unresolved alert of the same severity is reused
  5. Human review Accept, Reject or Escalate

What I built

  • Led the team and developed the working web prototype: a FastAPI backend, SQLAlchemy with SQLite for storage, and an HTML, CSS and JavaScript interface.
  • Implemented the rule-based environmental-stress assessment that classifies each batch as Healthy, Warning or Critical.
  • Implemented alert deduplication, so a batch with an unresolved alert of the same severity reuses it instead of creating another.
  • Built the review step where a person accepts, rejects or escalates each alert.

Human-in-the-Loop Escalation Architecture for NLU Deployments

B.Tech capstone project

Team lead In progress

Conversational systems misread requests, and some mistakes are expensive to undo. This system evaluates each request and decides whether to proceed with automated processing or escalate it to a human reviewer. The example at the top of this page shows the idea.

Checks on every request

  • Confidence of the language understanding
  • Risk of the requested operation
  • Presence and validity of critical entities

Designed for four domains

  • Travel and airline services
  • Food ordering
  • E-commerce
  • Appointment scheduling

My part

  • Lead the team and coordinate the work.
  • Built the FastAPI backend and the decision logic that combines confidence checks, operation-risk checks and critical-entity validation.
  • Implemented the human-review workflow.
  • Contributed to the SQLAlchemy database integration and to connecting the backend APIs with the frontend for request evaluation, escalation handling and evaluation history.

Built with Python, FastAPI, Pydantic, SQLAlchemy, PostgreSQL, SQLite, Uvicorn
